# 八字分析

结构化、直断、可复核的中文八字分析 skill。

## 能做什么

- 按输入的出生年月日时直接排盘
- 分析日主、旺衰、十神、格局、用神与刑冲合害
- 结合古籍断语说明传统依据
- 直断财富、事业、学业、感情、健康倾向与大运流年
- 用过往事件做支持、不支持、无法区分的校验
- 把命理结构转译为诗句、风景和人物意象
- 生成五种统一主题的命理画像：国风水墨、清冷古风、影视写实、东方插画、CG

## 使用

在 Codex 中调用 $bazi-analysis，提供出生年月日时、性别和希望重点。默认按用户输入的时辰排盘，不自动引入真太阳时。用户同意生成图像时，默认覆盖上述五种风格。

## 边界

古籍断语属于传统命理文本，不是现代科学证据；skill 不把命盘换算成人民币资产上限，也不诊断疾病、寿命或事故。
